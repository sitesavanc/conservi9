# Conserv I9 · site (versão para visualização)

Site da **Conserv I9**, desentupidora 24h em Curitiba, RMC, litoral do PR e Itapoá (SC).
Desenvolvido por **AVANC Comercial & Marketing** · [instagram.com/avancmkt](https://instagram.com/avancmkt)

## Como ver

- **No computador:** baixe a pasta e dê dois cliques em `index.html`. O menu e os links funcionam normalmente.
- **No GitHub Pages:** em *Settings → Pages*, escolha a branch `main` e a pasta `/ (root)`. Em um minuto o site abre em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## O que observar

- Os textos marcados em **laranja tracejado** `[ASSIM]` são informações que ainda faltam (CNPJ, cidades, prazos etc.). Elas saem do site antes de ir ao ar.
- As artes com o selo `[FOTO: ...]` serão trocadas por fotos.
- Nesta cópia o formulário não envia e-mail: ele leva os dados para o WhatsApp. No site oficial (HostGator), envia por e-mail.
- Esta cópia está marcada para **não aparecer no Google**, para não competir com o site oficial.
